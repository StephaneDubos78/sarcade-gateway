# SARCADE Gateway

Passerelle terrain entre SARCADE et les transports radio/IP.

## Cibles
Mini-PC, Raspberry Pi, AdraBox, VM et plateformes Linux compatibles.

## Connecteurs prévus
Meshtastic, MeshCore, APRS, AX.25/Packet, Reticulum/LXMF, Winlink, SDR et plugins complémentaires.
